## 二、新增技术组件

| 组件 | 技术 | 用途 |
|-----|------|------|
| **OCR** | 腾讯云通用印刷体识别 | 菜单文字识别 |
| **菜品理解** | 通义千问 | 解析菜品、价格、分类 |
| **图片存储** | 自建服务器 | 存储菜单图片 |

## 三、新增数据模型

```sql
-- 用餐记录
dining_records (
  id, user_id, restaurant_id,
  members,        -- JSON: 参与成员
  total_cost,     -- 实际消费
  rating,         -- 评分
  notes,          -- 备注
  dined_at, created_at
)

-- 点餐记录
order_records (
  id, dining_record_id,
  menu_image_url,     -- 菜单图片
  dishes,             -- JSON: 点的菜品
  total_price,
  created_at
)

-- 群组
groups (
  id, user_id, name,
  member_ids,     -- JSON: 成员ID列表
  created_at
)
```

## 四、新增 API 接口

| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/ocr/menu` | POST | 菜单 OCR 识别 |
| `/api/dish/parse` | POST | AI 解析菜品信息 |
| `/api/dish/recommend` | POST | 点菜推荐 |
| `/api/dining-records` | GET/POST | 用餐记录 |
| `/api/groups` | GET/POST/PUT/DELETE | 群组管理 |

## 五、点菜推荐流程

```
用户拍摄菜单
    │
    ▼
┌───────────────────┐
│ 1. OCR 识别文字   │ 腾讯云 OCR
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ 2. AI 解析菜品    │ 通义千问
│  - 菜名、价格     │
│  - 分类、特点     │
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ 3. 获取用户参数   │
│  - 人数、预算     │
│  - 成员偏好       │
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ 4. AI 组合推荐    │
│  - 预算优化       │
│  - 荤素搭配       │

          ▼

└───────────────────┘
```

## 八、风险与应对

| 风险 | 应对措施 |
|-----|---------|
| OCR 识别不准 | 支持手动编辑修正 |
| 菜单格式多样 | 先支持标准打印菜单 |
| AI 调用成本增加 | 设置每日免费次数限制 |
