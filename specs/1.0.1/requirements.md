# 吃了么 (Eato) - 1.0.1 需求文档

## 版本概述

1.0.1 版本在 1.0.0 基础上，新增**智能点菜**功能，帮助用户在餐厅解决"点什么菜"的问题。

## 前置依赖

- 1.0.0 已上线并稳定运行

## V2 新增功能

### 1. 点什么菜（新增 Tab）

拍摄菜单，AI 自动识别并根据预算和偏好推荐最佳点餐方案。

**功能点：**
- 拍摄 / 上传菜单图片
- AI 菜单识别（OCR + 菜品理解）
- 设置点餐参数：
  - 用餐人数
  - 总预算
  - 选择用餐成员（复用吃货档案偏好）
- AI 智能推荐：
  - 根据预算优化菜品组合
  - 兼顾荤素搭配、口味多样性
  - 考虑成员偏好和禁忌
  - 支持多套方案对比
- 点餐清单：
  - 展示推荐菜品及价格
  - 支持手动调整（增删菜品）
  - 实时计算总价

### 2. 用餐记录

**功能点：**
- 记录历史用餐餐厅
- 支持评价和备注
- 查看历史点餐记录
- 基于历史数据优化推荐

### 3. 多人群组（可选）

**功能点：**
- 创建常用聚餐群组（同事午餐组、家庭聚餐组）
- 快速选择群组成员
- 综合群组成员偏好推荐

### 4. 社交分享（可选）

**功能点：**
- 分享推荐结果给好友
- 分享点餐方案
- 邀请好友加入群组

```
│   ├── 菜品识别结果
│   ├── 设置点餐参数
│   ├── AI 推荐方案

```

## 技术要点

| 模块 | 技术方案 |
|------|----------|
| OCR | 腾讯云通用印刷体识别 |
| 菜品理解 | 通义千问 + 菜品知识库 |
| 图片存储 | 自建服务器 / 对象存储 |

## 风险点

| 风险 | 影响 | 应对措施 |
|-----|------|---------|
| OCR 识别不准 | 菜品识别错误 | 支持手动编辑修正 |
| 菜单格式多样 | 解析困难 | 先支持标准打印菜单，手写/复杂排版后续优化 |
| AI 成本 | 费用增加 | 设置每日免费次数限制 |

## 非功能性需求

- **性能**：菜单识别 < 5秒，点菜推荐 < 3秒
- **准确率**：OCR 识别准确率 > 90%（标准打印菜单）
