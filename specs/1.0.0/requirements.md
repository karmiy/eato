# 吃了么 (Eato) - 1.0.0 需求文档

## 项目简介

"吃了么"是一款帮助用户解决"选择困难症"的微信小程序。1.0.0 版本聚焦于**餐厅推荐**功能，帮助用户快速决定"去哪家吃"。

## 目标用户

- 经常纠结"吃什么"的上班族
- 对周边餐厅不熟悉的用户
- 希望快速做出用餐决策的用户

## 平台

微信小程序

## V1 功能范围

### 1. 吃哪家（首页 - 核心功能）

摇一摇推荐餐厅，帮用户做决定。

**功能点：**
- 摇一摇 / 点击按钮触发推荐
- 设置筛选条件：
  - 距离范围（500m / 1km / 3km / 5km）
  - 人均预算（不限 / ¥30以下 / ¥30-60 / ¥60-100 / ¥100以上）
  - 菜系筛选
- 自动过滤未营业餐厅
- 展示推荐结果：
  - 餐厅照片、名称、评分、人均
  - 距离、地址、营业时间
  - AI 推荐理由
- 操作：
  - 换一家（本次会话不再推荐）
  - 就这家（跳转详情/导航）
  - 不再推荐（加入黑名单）
- 摇一摇逻辑：
  - 点击"换一家"后，本次会话内不再推荐该餐厅
  - 支持"不再推荐"将餐厅加入黑名单
  - 近期去过的餐厅降低推荐权重
  - 收藏的餐厅可正常出现
  - 候选不足时提示放宽筛选条件

### 2. 餐厅详情

**功能点：**
- 餐厅照片轮播
- 基本信息（名称、评分、人均、距离、营业时间）
- 导航（跳转高德/微信地图）
- 收藏 / 取消收藏
- 用餐后反馈（好吃👍 / 踩雷👎）

### 3. 我的

**功能点：**
- 吃货档案（成员偏好管理）
  - 添加/编辑/删除成员
  - 口味偏好（辣/甜/酸/咸）
  - 菜系偏好
  - 饮食禁忌
  - 预算范围
- 我的收藏
- 黑名单管理
- 设置

## 页面结构

```
Tab 结构（2个）：
├── 🎰 吃哪家（首页）
│   ├── 摇一摇入口
│   ├── 筛选条件
│   └── 推荐结果页
│       ├── 换一家 / 就这家
│       └── 餐厅详情
│
└── 👤 我的
    ├── 吃货档案
    ├── 我的收藏
    ├── 黑名单管理
    └── 设置
```

## 非功能性需求

- **性能**：首页加载时间 < 2秒，推荐响应 < 3秒
- **兼容性**：支持 iOS 和 Android 微信客户端
- **安全性**：用户数据加密存储，遵循微信小程序隐私规范
