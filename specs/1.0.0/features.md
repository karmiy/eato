# Eato v1.0.0 功能规格

> 版本定位：解决「今天吃什么」的核心决策问题，不含点菜功能

---

## 功能清单（按对接顺序）

### 1. 成员管理（吃货档案）
| 状态 | 功能 | API | 说明 |
|:---:|------|-----|------|
| 🔄 | 成员列表 | `GET /api/members/{user_id}` | 获取用户所有成员 |
| 🔄 | 创建成员 | `POST /api/members` | 新建吃货档案 |
| 🔄 | 编辑成员 | `PUT /api/members/{id}` | 修改档案信息 |
| 🔄 | 删除成员 | `DELETE /api/members/{id}` | 删除成员 |

**数据字段**：姓名、口味偏好（辣度）、菜系偏好、饮食禁忌、预算范围、备注

---

### 2. 餐厅推荐（核心功能）
| 状态 | 功能 | API | 说明 |
|:---:|------|-----|------|
| ⬚ | 智能推荐 | `POST /api/recommend` | 根据参与成员偏好推荐餐厅 |
| ⬚ | 随机决定 | `POST /api/recommend/random` | 从推荐结果中随机选一个 |
| ⬚ | 换一批 | `POST /api/recommend/refresh` | 刷新推荐结果 |

**推荐逻辑**：
- 综合所有参与成员的口味偏好
- 排除黑名单餐厅
- 考虑预算范围
- 根据距离、评分排序

---

### 3. 收藏管理
| 状态 | 功能 | API | 说明 |
|:---:|------|-----|------|
| ⬚ | 收藏列表 | `GET /api/favorites/{user_id}` | 获取收藏的餐厅 |
| ⬚ | 添加收藏 | `POST /api/favorites` | 收藏餐厅 |
| ⬚ | 取消收藏 | `DELETE /api/favorites/{id}` | 移除收藏 |

---

### 4. 黑名单管理
| 状态 | 功能 | API | 说明 |
|:---:|------|-----|------|
| ⬚ | 黑名单列表 | `GET /api/blacklist/{user_id}` | 获取拉黑的餐厅 |
| ⬚ | 添加黑名单 | `POST /api/blacklist` | 拉黑餐厅 |
| ⬚ | 移除黑名单 | `DELETE /api/blacklist/{id}` | 解除拉黑 |

---

### 5. 用餐反馈
| 状态 | 功能 | API | 说明 |
|:---:|------|-----|------|
| ⬚ | 反馈列表 | `GET /api/feedback/{user_id}` | 获取历史反馈 |
| ⬚ | 提交反馈 | `POST /api/feedback` | 记录用餐体验 |
| ⬚ | 删除反馈 | `DELETE /api/feedback/{id}` | 删除记录 |

**反馈内容**：评分（1-5）、评价文字、用餐日期

---

### 6. 用户设置
| 状态 | 功能 | API | 说明 |
|:---:|------|-----|------|
| ⬚ | 获取设置 | `GET /api/settings/{user_id}` | 获取用户配置 |
| ⬚ | 更新设置 | `PUT /api/settings/{user_id}` | 修改配置 |

**设置项**：默认搜索半径、默认排序方式、主题偏好

## 依赖说明

```
1. 成员管理 ──────────────────────┐
                                  ↓
2. 餐厅推荐 ←─── 需要成员偏好数据
      ↓
      ├─→ 3. 收藏管理（推荐结果可收藏）
      ├─→ 4. 黑名单管理（推荐结果可拉黑）
      └─→ 5. 用餐反馈（去吃后可反馈）

6. 用户设置 ──────────────────────（独立，随时可做）
```
