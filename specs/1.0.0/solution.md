```
┌─────────────────────────────────────────────────────────────┐
│                      微信小程序                              │

└───────────────────────┬─────────────────────────────────────┘
                        │ HTTPS
┌───────────────────────▼─────────────────────────────────────┐
│                    后端服务（自建）                          │
│       ┌──────────────┐         ┌──────────────┐            │
│       │   用户服务    │         │   推荐服务   │            │
│       └──────────────┘         └──────────────┘            │
└───────────────────────┬─────────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────────┐
```

## 二、技术选型

| 层级 | 技术 | 选型理由 |
|-----|------|---------|
| **前端** | 微信小程序原生 | 性能最优，微信生态兼容性好 |
| **后端** | Python + FastAPI | 语法简洁、AI 生态好、异步支持 |
| **数据库** | MySQL | 自建服务器，完全可控 |
| **餐厅数据** | 高德地图 API | 已验证，数据完整 |
| **AI 推荐** | 通义千问 (Qwen) | 国内稳定、免费额度充足，详见 [ADR-001](./adr/001-ai-recommendation-strategy.md) |
| **部署** | 自建服务器 | 已有服务器资源 |

## 三、数据模型

```sql
-- 用户表
users (
  id, openid, nickname, avatar, created_at
)

-- 成员表（吃货档案）
members (
  id, user_id, name, avatar,
  taste_preferences,    -- JSON: {spicy: 3, sweet: 2}
  cuisine_preferences,  -- JSON: ["川菜", "粤菜"]
  dietary_restrictions, -- JSON: ["花生过敏"]
  budget_range,         -- JSON: {min: 30, max: 80}
  created_at
)

-- 餐厅黑名单
restaurant_blacklist (
  id, user_id, restaurant_id, created_at
)

-- 餐厅反馈
restaurant_feedback (
  id, user_id, restaurant_id, 
  rating,      -- 1=踩雷, 2=一般, 3=好吃
  visited_at, created_at
)

-- 收藏
favorites (
  id, user_id, restaurant_id, created_at
)
```

## 四、API 接口

| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/members` | GET/POST/PUT/DELETE | 成员 CRUD |
| `/api/recommend` | POST | 获取餐厅推荐 |
| `/api/recommend/next` | POST | 换一家 |
| `/api/feedback` | POST | 提交用餐反馈 |
| `/api/blacklist` | POST/DELETE | 黑名单管理 |
| `/api/favorites` | GET/POST/DELETE | 收藏管理 |

## 九、风险与应对

| 风险 | 影响 | 应对措施 |
|-----|------|---------|
| 高德 API 调用超限 | 功能不可用 | 缓存热门区域数据 |
| AI 成本过高 | 亏损 | 简单场景用规则引擎 |
| 冷启动无数据 | 推荐不准 | 默认推荐高分热门 |
